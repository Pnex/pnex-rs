# Audit du dépôt du 2026-11-06 : constats à discuter

Audit en lecture seule (5 lecteurs parallèles : authentification et
cloisonnement, écritures de données, runtime de flows et devices,
assistant/MCP/secrets, code en trop et tests). Rien n'a été compilé ni
exécuté. ✔ = relu dans le code à la main après le lecteur.

Statut de tout le document : **à discuter**, rien n'est corrigé. Les
constats de sécurité sont aussi inscrits au registre `security.md` §7
(SEC-67 à SEC-79) ; les constats de pipelines sont rattachés au plan de
`test-grandeur-nature-2026-11-06.md` (lot A).

Charge supposée : SaaS de quelques dizaines d'orgs sur un runtime de flows
partagé, des milliers de devices, imports de nuit, plusieurs réplicas du
backend.

## 4. Vérifié et sain

JWT (RS256, `iss`/`aud`/`exp`), `OrgContext` depuis l'appartenance, aucun
accès inter-org par id trouvé (25 sites `find_by_id` sur ~190 relus),
jetons machine filtrés par org, comparaisons en temps constant, coffre
(nonce aléatoire, AAD org + secret, rotation), redaction MCP sur les 404
opérations exposées, uploads (liste blanche, `nosniff`, CSP bac à sable),
garde de sortie sur crawler / IMAP / SMTP / LLM / navigateur serveur, clés
mémoire Valkey avec org et TTL, sweeps singleton sous bail, effacement face
aux pipelines en cours, claims `SKIP LOCKED`.
