Sites (Monitor › Sites) lists every site of the organization on a full page, without the map: the "where" view of everything installed. A site is the same object as a point of interest on the Map; Sites and Map are two views of one tree.

## What you can do
- **Search** a site, open it: the panel shows its tree — folders (building, floor, room…), then the attached devices, dashboards, media and 3D tours. Drag objects between folders with the ⠿ handle, create a folder (**+ Folder**), attach an object (**Attach an object**), preview it, pin it (★), set the site's **Labels**.
- **New site** creates a site from its name and pictogram; the coordinates start on a default point and can be typed (or move the site later on the Map).
- **Map view** goes to the Map; on the Map, **List view** comes back here.
- Every detail page shows the object's **Location** — "Site › folder › folder" — and each step opens that site here. A device has one location; a media, a tour or a dashboard can be attached to several sites. "Not placed on any site yet" means the object is in no site: open Sites and attach it.

## Good to know
- Labels belong to the object that carries them, a folder's labels stay on the folder (filter any list with `name` or `name:value`).
- A device sits on one site only: attaching it elsewhere asks to move it.
