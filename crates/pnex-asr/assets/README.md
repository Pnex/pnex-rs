# Reference sample of the model check

`check-fr.wav` (16 kHz mono, 7.6 s) and its transcript `check-fr.txt` come
from the FLEURS dataset (Google, `fr_fr` test split, utterance
`7989253100718399733`), licensed under CC BY 4.0
(https://creativecommons.org/licenses/by/4.0/). The audio was converted
from 32-bit float to 16-bit PCM; nothing else was changed.

Conneau et al., "FLEURS: Few-shot Learning Evaluation of Universal
Representations of Speech", 2022.

The model check (media-ingest.md D167) transcribes it to measure the load
time, the real-time factor and the word error rate of an imported model.
